# 星铁配队与货币战争顾问 · AstrBot

一个插件内含中文 Skill 和三个数据查询工具。群友可以问常规队伍怎么配、两张光锥如何取舍，也可以把本局货币战争的金币、等级、员工和商店发给机器人，询问下一步。玩法数据由插件按需获取，建议由机器人现有的模型结合玩家局面生成。

## 安装

1. 在 AstrBot **4.29.4 或以上的 4.x 版本**打开 WebUI 的「插件」，选择从链接安装，粘贴本仓库地址。
   `https://github.com/YouKnowWh/astrbot_plugin_hsr_advisor`
2. 启用插件，并确保群聊使用的配置允许该插件、模型支持工具调用。使用 AstrBot 内置 Agent，在「插件 → 技能」中确认 `hsr-advisor` 已启用，当前人格能读取 Skill。要直接看群友截图，群聊还需启用能读图的模型；文字局面也能使用。
3. 群里发送 `/星铁数据` 检查两个数据源，再按群里平时的方式唤醒机器人。插件复用已有模型配置，查询游戏数据无需游戏账号、Cookie 或额外 API Key。

## 可以这样问

- 「希儿带叠影 1 的于夜色中，队友有布洛妮娅、佩拉和娜塔莎。打单体时开局怎么分配战技点？」
- 「货币战争想围绕阿格莱雅玩，帮我找本赛季的前中后期阵容和装备顺序。」
- 「这是这轮商店和场上阵容，我该买人还是升人口？先给这轮的操作。」附截图，或用文字描述金币、等级、星级及商店候选。

## 数据怎么更新

| 内容 | 数据来源 | 自动刷新 |
| --- | --- | --- |
| 常规角色、行迹、星魂、光锥和叠影 | [StarRailRes 中文数据](https://github.com/Mar-7th/StarRailRes/tree/master/index_min/cn) | 随安装包附带可离线查询的角色与光锥快照。首次查询也会尝试在线核对。之后每 6 小时在下次查询时检查上游提交。有变化就用同一个提交重新读取整组数据，已有角色和光锥的改动也会更新。 |
| 当季员工、羁绊、装备、投资环境、投资策略、主角光环 | 米游社「货币战争」公开配置接口 | 每小时在下次查询时获取版本、赛季和条目。 |
| 社区阵容、前后台站位、装备和过渡思路 | [米游社货币战争阵容工具](https://act.miyoushe.com/sr/event/currency-wars/index.html) | 按赛季与核心员工缓存 1 小时，取热度首页中版本和赛季相符的最多三条，过滤已过期阵容。 |

常规资料整轮联网刷新最多等待 8 秒。上游不可用时从本地缓存或随包资料返回，回复携带资料状态和来源日期；同时到来的其他常规查询直接使用手头资料。随包快照涵盖 99 份角色条目和 172 张光锥，来源见 [StarRailRes 说明](data/StarRailRes/README.md)。

无人提问期间不轮询。缓存保存在 AstrBot 的插件数据目录 `plugin_data/astrbot_plugin_hsr_advisor/`。刷新失败会保留上一份成功数据，返回缓存时间，1 分钟后可重试。新版本收录时间取决于上游。服务器需要能访问 `api.github.com`、`raw.githubusercontent.com` 和 `act-api-takumi.miyoushe.com`。接口结构变化时，插件代码可通过 AstrBot 的插件更新功能升级。

常规数据是社区整理的基础数值。涉及玩家实际遗器、速度、战技点和当期关卡增益时，应结合玩家提供的信息。阵容攻略来自社区，没有胜率统计。插件只读取资料并提供建议，所有游戏操作由玩家完成。

工作流参考 [HSR Data Bank](https://github.com/cuiko/hsr-databank) 和 [Trail CLI](https://github.com/jiwangyihao/trail-cli)。本仓库包含独立实现的查询工具与 Skill；游戏数据和素材的权利归各自权利人。AstrBot 的技能配置见[官方文档](https://docs.astrbot.app/use/skills.html)。
